## Signed URL 

When your S3 bucket is private, so nobody can directly open files from it. A signed URL is a special URL generated by AWS that contains a secure signature proving that your server has authorized access to that specific file. 

The user doesn't need AWS credentials. 

**Why does it expire?**

If the URL never expired, anyone who got hold of it could access the file forever by sharing or saving the link. 

By expiring it (e.g., after 5 minutes), AWS automatically invalidates the URL, so the user must request a new one from your backend. This keep private files secure.
